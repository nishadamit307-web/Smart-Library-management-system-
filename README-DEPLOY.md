# Smart Library — GitHub Pages Website

Responsive static showcase website for the Smart Library Management System.

## Files
- `index.html` — website structure
- `styles.css` — responsive design
- `script.js` — mobile navigation and sample book lookup demo

## Publish on GitHub Pages
1. Open your repository: https://github.com/nishadamit307-web/Smart-Library-management-system-
2. Click **Add file → Upload files**.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root (not inside a nested folder).
4. Click **Commit changes**.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/(root)`, then click **Save**.
8. Wait a few minutes and open the URL shown in Settings → Pages. The expected project URL is:
   `https://nishadamit307-web.github.io/Smart-Library-management-system-/`

## Important
This is a static front-end showcase. The sample book lookup is illustrative only; it does not connect to the Python application, database, camera, or physical hardware. GitHub Pages does not run Python server-side code. A fully working web application needs a separately hosted backend.
